# Painel administrativo — VoltX

Reservado à aplicação Next.js + TypeScript do painel administrativo, separada do site público. Consome a mesma API com autenticação e permissões; não deve conter páginas públicas nem acesso direto ao PostgreSQL.

Referências: [Arquitetura](../../docs/ARQUITETURA.md).

O diretório possui manifesto package.json e é reconhecido pelo pnpm como membro do workspace. Framework, código e dependências específicas ainda não foram inicializados.
