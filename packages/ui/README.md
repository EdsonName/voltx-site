# Componentes compartilhados — VoltX

Reservado aos componentes visuais reutilizáveis entre site e painel, conforme o Design System VoltX. Não deve concentrar regras de negócio ou acesso direto ao banco.

Referências: [Arquitetura](../../docs/ARQUITETURA.md) e [documentação específica](../../docs/DESIGN.md).

O diretório possui manifesto package.json e é reconhecido pelo pnpm como membro do workspace. Framework, código e dependências específicas ainda não foram inicializados.
