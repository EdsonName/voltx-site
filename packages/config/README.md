# Configurações compartilhadas — VoltX

Reservado às configurações técnicas compartilhadas entre as aplicações do monorepo. Não deve conter segredos, credenciais ou dados comerciais mutáveis que pertencem à fonte central do negócio.

Referências: [Arquitetura](../../docs/ARQUITETURA.md).

O diretório possui manifesto package.json e é reconhecido pelo pnpm como membro do workspace. Framework, código e dependências específicas ainda não foram inicializados.
